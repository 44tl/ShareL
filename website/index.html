Core Capabilities

Everything you need for daily screen capture, recording, and sharing.

ShareX (.sxcu) Destinations

Import `.sxcu` files directly. Supports multipart form data, JSON payloads, headers, regexes, and vanity domain mappings.

Intelligent Wayland Router

Automatically selects the fastest capture pipeline between XDG Desktop Portal, direct `grim`/`slurp`, and compositor IPC.

GPU Recording Studio

Smooth 60/120 FPS recording via `gpu-screen-recorder` (NVENC / VAAPI) and `wf-recorder` for video and palette-optimized GIFs.

Annotations & Privacy Redaction

Add arrows, step markers, rectangles, freehand brush strokes, and pixelate credentials and tokens before sharing.

Keybindings & CLI Reference

Easily bind ShareL to your window manager shortcuts or terminal scripts.

Niri Config (~/.config/niri/config.kdl)
binds {
    Print     { spawn "sharel" "capture" "region"; }
    Mod+Print { spawn "sharel" "capture" "region" "--upload"; }
    Alt+Print { spawn "sharel" "capture" "window"; }
}
Hyprland & Sway Config
# Hyprland
bind = , Print, exec, sharel capture region
bind = SUPER, Print, exec, sharel capture region --upload

# Sway
bindsym Print exec sharel capture region
