Precision Tools for Power Users

Everything you loved about ShareX, engineered natively for Wayland and modern Linux desktops.

Pure Wayland Capture

Direct XDG Desktop Portal and Grim/Slurp integration. Interactive area selection with sub-millisecond response on GNOME, KDE Plasma, Sway, and Hyprland.

ShareX .sxcu Compatibility

Import your existing ShareX custom uploaders without modification. Full JSONPath, regex response extraction, and custom headers support for any image host or S3 destination.

Two-Pass Palettegen GIF

Record crisp, high-framerate animated GIFs optimized for Discord and web embeds with automated palette generation via FFmpeg and wf-recorder.

Instant Obfuscation & Steps

Protect API keys and passwords with pixelation boxes. Number your bug reproduction steps with auto-incrementing numbered badge bubbles.

After-Capture Automation

Configure complete multi-step pipelines: auto copy to clipboard, save to customized folder patterns, auto upload, and play notification cues.

Screen Color Picker & OCR

Instant pixel color sampler supporting HEX, RGB, and HSL formats. Built-in OCR powered by Tesseract to extract selectable text from any image.

ShareX .sxcu Custom Uploader Engine

Test and simulate your custom destinations directly in browser.
